# BMC1 Chain 137 Stable Coins

A live dashboard of stablecoins deployed on **Polygon (Chain 137)** — showing real-time USD prices, 7-day sparklines, and verified contract addresses against a starry-night cosmic backdrop.

🔗 **Live:** https://github.com/BeMyCrypto1/BMC1-StableCoins/
🔗 **Live Dashboard:** [https://bemycrypto1.github.io/BMC1-StableCoins/](https://bemycrypto1.github.io/BMC1-StableCoins/)

---

## ✨ Features

- 🌌 **Starry night visuals** — animated starfield with drifting planets, spiral galaxies, nebula wisps, and shooting stars
- 💰 **Live prices** — fetched from [DefiLlama](https://defillama.com) (keyless, no API needed)
- 📊 **Auto-categorized columns** — Pegged ~$1.00, Below $0.90, Above $1.00
- 📈 **7-day sparklines** — mini price charts per token, colored by trend
- 🔍 **Search/filter** — by name, symbol, or contract address
- 📋 **Click-to-copy** — copy any contract address with one click
- 🔄 **Auto-refresh** — prices update every 60 seconds (manual refresh also available)
- 📱 **Responsive** — works on desktop, tablet, and mobile

---

## 🚀 Usage

Just open the page. No install, no build step, no API key.

- Prices auto-refresh every 60 seconds
- Click the **Refresh** button anytime for an instant update
- Click any contract address to copy it, or the **↗** to open Polygonscan
- Type in the search box to filter across all three columns

---

## 🛠 Tech

- Single self-contained `index.html` — no framework, no dependencies
- Vanilla JS + Canvas for the animated cosmos
- [DefiLlama Coins API](https://defillama.com/docs/api) for prices and charts

---

## 📦 Tokens Tracked

55+ stablecoins across multiple currencies (USD, EUR, GBP, CHF, BRL, MXN, JPY, SGD, IDR, PHP, AUD, NZD, and more) — including USDC, USDT0, DAI, PYUSD, EURC, EURe, XSGD, and others.

Tokens without a live market price are automatically hidden.
